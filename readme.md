# CShell

CShell is a simple command shell simulation program written in C. It allows users to interact with the terminal through basic command-line inputs, mimicking the functionality of a traditional shell environment.

## Features

- **Command Simulation**: Implements essential commands such as:
  - `cd`: Change the current directory.
  - `help`: Display a list of available commands.
  - `exit`: Terminate the shell session.
  - `next`: Creates a next-js project with the provided name args[1]

- **User Input**: Accepts and processes user commands in real-time.
- **Basic Error Handling**: Provides feedback for invalid commands or errors.

## Requirements

- C Compiler (e.g., gcc)
- A Unix-like operating system (Linux, macOS)
